# Portfolio

Run the development server:

```sh
npm run dev
```

Open `http://localhost:3000` on this computer, or the Network URL printed by
Next.js (for example, `http://172.20.20.73:3000`) from a device on the same network.

`next.config.mjs` allows this computer's IPv4 addresses to load Next.js development
assets. Restart `npm run dev` after changing networks or IP addresses so the
allowlist refreshes.
